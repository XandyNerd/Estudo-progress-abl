# Jornada de Estudos Progress OpenEdge ABL

Repositório dedicado ao registro do meu aprendizado em Progress OpenEdge ABL. Cada pasta representa uma etapa ou projeto específico.

## 🚀 Projetos Atuais

### 1. Sistema Infocena (Estudo Inicial)
Um sistema de estudo focado em interface gráfica (GUI), autenticação e manipulação de banco de dados.

**O que aprendi até agora:**
- Configuração de ambiente Progress.
- Criação de telas de Login e Registro.
- Conexão com banco de dados `.db` via linha de comando (`prowin.exe`).
- Organização de scripts executáveis para facilitar o desenvolvimento.

---

## 🛠️ Como rodar o projeto
1. Certifique-se de ter o Progress OpenEdge instalado em `C:\Progress\OpenEdge`.
2. Acesse a pasta `executaveis/`.
3. Use o `Abrir_Editor.bat` para carregar o ambiente com o banco conectado.
